# Daniel Ovedal - regressionstestutkast

Den här katalogen är den personliga arbetsytan för Daniels regressionstestutkast.

## Regler

- lägg nya eller experimentella testdefinitioner här innan de promotas
- använd GitHub-stil på användarnamnet i katalognamnet när andra användare får egna draft-ytor
- lägg inte lokala rapporter, screenshots eller kördump här; sådant ska sparas i `tmp\regression_local\danielolvedal\reports`
- när ett test ska delas, flytta det till `testing\regression_test` och uppdatera katalog, beroendegraf och dokumentindex
