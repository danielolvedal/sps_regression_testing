# Syntetisk data - index

Detta index är ingången till den normaliserade kunskapsbas som ska ligga till grund för manualer, one-pagers, instruktioner och säljmaterial.

## Syfte

Syntetisk data ska:

- sammanfatta och normalisera råmaterial från `raw_data`
- gruppera SPS-funktioner på ett sätt som stödjer dokumentproduktion
- tydliggöra vad som är verifierat, osäkert eller saknas
- kunna byggas ut stegvis utan att struktur eller terminologi bryts
