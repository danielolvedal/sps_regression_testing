# Bilder för syntetisk data

## Syfte

Den här katalogen reserveras för bilder och andra visuella artefakter som stödjer syntetiska dokument och senare manualproduktion.

## Regler

- Bilder ska organiseras så att de speglar dokumentstrukturen
- Filnamn ska beskriva dokument och steg, exempelvis `skapa-kontrakt-step-01.png`
- Tillhörande syntetiskt dokument ska referera till bilden under sektionen `Bilder och visuellt underlag`
- Om ett dokument saknar bilder ska sektionen ändå finnas kvar i dokumentet
